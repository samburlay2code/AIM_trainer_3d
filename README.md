# 3D Aim Trainer - User Guide

## Overview
3D Aim Trainer is a browser-based FPS aim training tool built with Three.js. It helps improve your mouse accuracy and reaction time through various training modes.

## Getting Started

### Launching the Application
1. Open `3D aim trainer.html` in any modern web browser (Chrome, Firefox, Edge)
2. The game interface will load with a 3D environment and control panel

### Basic Controls
- **Mouse Movement**: Look around the 3D environment
- **Left Click**: Shoot targets
- **Click on Game Area**: Capture cursor for FPS-style controls
- **ESC**: Release captured cursor

## Game Modes

### GridShot
- Static targets appear in fixed positions
- Click targets as fast as possible
- Best for practicing basic accuracy and click speed

### Tracking
- Follow moving targets with your crosshair
- Hold your aim on targets to score points
- Improves smooth tracking ability

### Moving
- Targets move across the field
- Shoot them before they disappear
- Trains flick shots and target switching

## Control Panel Settings

### Mode Section
- **Mode**: Select between GridShot, Tracking, or Moving
- **Size**: Target size (5-30). Smaller = harder
- **Speed**: Target movement speed (1-20)
- **Wobble**: Unpredictable movement pattern (0-10)
- **Count**: Number of simultaneous targets (1-15)

### Difficulty Section
- **Duration**: Game session length (30-180 seconds)
- **Difficulty**: Preset configurations
  - Novice: Larger targets, slower speed
  - Medium: Balanced settings
  - Expert: Smaller targets, faster speed
  - Pro: Maximum challenge

### Effects
Visual feedback when hitting targets:
- **Glow**: Soft glow effect
- **Particles**: Particle explosion
- **Ring**: Expanding ring
- **Burst**: Radial burst
- **Sparks**: Spark particles
- **None**: No visual effects

### Game Buttons
- **Start**: Begin training session
- **Stop**: End current session
- **Pause**: Pause/resume game
- **Fullscreen**: Toggle fullscreen mode
- **Sound**: Toggle sound effects on/off
- **Menu**: Toggle control panel visibility

## HUD Information

Real-time stats displayed during gameplay:
- **Time**: Remaining time in session
- **Score**: Total points earned
- **Accuracy**: Hit percentage
- **Combo**: Current hit streak
- **Timer Display**: Large countdown timer (visible during game)

## How to Play

1. **Configure Settings**: Adjust mode, difficulty, and preferences
2. **Click Start**: Game begins after 3-second countdown
3. **Aim and Shoot**: 
   - Click game area to capture cursor
   - Use mouse to aim
   - Left-click to shoot targets
4. **Complete Session**: Play until time runs out or click Stop
5. **Review Stats**: See detailed performance metrics after each session

## Tips for Improvement

- Start with larger targets and slower speeds
- Focus on accuracy before speed
- Practice different modes for well-rounded skills
- Use consistent mouse sensitivity
- Take breaks to avoid fatigue
- Track progress over multiple sessions

## Technical Notes

- Requires WebGL-enabled browser
- Best performance in Chrome/Edge
- Fullscreen recommended for immersive experience
- Cursor capture provides true FPS-style aiming

## Troubleshooting

**Cursor not capturing**: Click directly on the game area
**Poor performance**: Reduce target count or effects complexity
**Game not loading**: Ensure JavaScript is enabled
**Sound not working**: Check browser audio permissions
